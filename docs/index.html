Planner

A small planning interface that uses my real Apple Calendar instead of inventing another place for me to maintain the same schedule.

Why I made it

I already use Apple Calendar, so making a separate planner database would just give me two schedules to keep in sync. Planner reads and edits the real calendar instead.

How I use it

I can look at upcoming blocks, create or edit events, and start a Focus session from the relevant calendar item. The actual timer stays in Focus rather than being duplicated here.

The three-app setup

Planner handles planning, Focus handles the current work session, and Deadlock handles blocking. They are separate apps because I found that easier to reason about than one large productivity app.

Install

git clone https://github.com/ren-jop/planner.git
cd planner
./install.sh

Current state

The core calendar flow and Focus integration are working in the preview build. The internal executable is still called calmenu from earlier versions.
