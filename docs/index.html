Planner

A planning interface that keeps Apple Calendar as the source of truth while connecting scheduled blocks to Focus execution and Deadlock enforcement.

Author
Ren Jopson
Version
v0.8.1
Source
GitHub

What it does

Planner reads and edits EventKit events instead of creating a second calendar database.

The interface is organised around a command-center view, future time blocks and Focus history so planned work and actual work can be compared.

AI in this project

AI is central to the orchestration work: translating workflow ideas into concrete state/data models, reviewing integration paths across three apps, generating implementation options and maintaining a precise project handoff so the system can keep evolving without losing context.
