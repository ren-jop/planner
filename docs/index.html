Planner

A planning interface that keeps Apple Calendar as the source of truth and connects scheduled work to execution without creating a second calendar database.

SourceInstall preview

v0.8.1 preview

Engineering problem

A planner becomes fragile if it duplicates the calendar and invents another source of truth. This project instead treats EventKit as the scheduling backend and adds an execution layer around it.

Design

Planner reads and edits real calendar events, surfaces upcoming blocks and goals, and can launch Focus with the relevant planning context. Focus history then makes planned-versus-actual work visible.

Deadlock stays downstream of Focus, so planning an event does not accidentally trigger enforcement.

Install

Requires Apple's Command Line Tools. The current preview retains the internal app name calmenu for compatibility.

git clone https://github.com/ren-jop/planner.git
cd planner
./install.sh

Ownership

Planner owns planning context, Focus owns the active work session, and Deadlock owns enforcement. Each integration crosses a narrow boundary rather than sharing one mutable state model.
