Planner

A week timeline for time blocking in Apple Calendar, with half-hour slots, overlap checks and a direct handoff to Focus.

Why I made it

I already use Apple Calendar, so making a separate planner database would just give me two schedules to keep in sync. Planner reads and edits the real calendar instead.

How I use it

The week timeline shows the length of each event. I can click a half-hour slot to prepare a block, check overlaps, then start the scheduled work in Focus.

The three-app setup

Planner handles planning, Focus handles the current work session, and Deadlock handles blocking. They are separate apps because I found that easier to reason about than one large productivity app.

Install

git clone https://github.com/ren-jop/planner.git
cd planner
./install.sh

Current state

Planner is still a preview app. The internal executable is still called calmenu from earlier versions.
