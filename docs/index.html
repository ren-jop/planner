Planner

a native macOS planning command center by Ren Jopson connecting Apple Calendar, Focus and Deadlock.

Highlights

• Dashboard for Focus, goals, exams and time blocks
• Apple Calendar / EventKit editing and sync
• Start scheduled blocks directly in Focus
• Planned-vs-actual work history

Built for a connected workflow

Planner handles planning and Apple Calendar integration, Focus runs the work session, and Deadlock provides distraction enforcement.
