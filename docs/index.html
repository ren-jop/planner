Planner

A planning interface that keeps Apple Calendar as the source of truth while connecting scheduled blocks to Focus execution and Deadlock protection.

SwiftSwiftPMEventKitAppKit / SwiftUI
Author
Ren Jopson
Version
v0.8.1 preview
Source
GitHub

What it does

Planner reads and edits EventKit events instead of creating a second calendar database.

The command-center view surfaces upcoming work, goals or exams and recent Focus history.

Scheduled time blocks can be started in Focus, which then becomes the sole trigger for Deadlock protection.

AI in this project

AI is central to the orchestration work: translating workflow ideas into concrete state and data models, reviewing integration paths across three apps, generating implementation options and maintaining a precise project handoff so the system can evolve without losing context.
